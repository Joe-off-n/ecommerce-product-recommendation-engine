# Personalized E-commerce Recommendation Engine

This is a beginner-friendly data science inspired web project built using HTML, CSS, and JavaScript.

## Features
- Product listing section
- Category-based recommendation filtering
- Product ratings and prices
- Dark mode toggle
- Responsive layout

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Idea
This project simulates a simple product recommendation engine for an e-commerce platform. It recommends products based on selected category and rating.

## How to Run
1. Open the project folder in VS Code
2. Open `index.html` in your browser
